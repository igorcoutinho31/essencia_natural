# AGENTS.md

Instruções para assistentes de código que trabalhem neste repositório.

1. Ler e seguir `docs/REGRAS.md` (regras do projeto: não inventar dados,
   preço e estoque, design só com aprovação, limites do código de `src/`).
2. Ler `README.md` para o mapa do projeto e `docs/TODO-VERIFY.md` para o
   que ainda não está confirmado pela loja.
3. Rodar `npm test` antes de dar uma mudança por concluída.
